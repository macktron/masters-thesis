\section{Attention Variants}\label{sec:method:attention}

The encoder of \cref{sec:method:arch} uses standard self-attention, which treats a window as an unordered set of tokens and lets every pulse attend to every other pulse purely through learned query--key compatibility.
The only ordering cue available to it is whatever the input features themselves carry, in particular the \gls{toa}.
A radar recording, however, has strong pairwise structure: two pulses that are close in time, share a carrier frequency, have a similar pulse width, or arrive from a similar direction, are far more likely to originate from the same emitter or mode than an arbitrary pair.
This section describes two variants of the attention mechanism that make such structure explicit.
They are used as drop-in modifications of the \gls{mha} sub-layers of \cref{sec:method:arch}.
Each variant is evaluated separately against standard self-attention in \cref{ch:experiments}; combining the bias with \gls{rope} is not tested here.

Throughout, we write the attention logits of a single head over a window of $L$ pulses as
\begin{equation}\label{eq:method:attn_base}
  \mat{A} = \frac{\mat{Q}\mat{K}^{\top}}{\sqrt{d_k}},
  \qquad
  A_{ij} = \frac{\vect{q}_i^{\top}\vect{k}_j}{\sqrt{d_k}},
\end{equation}
where $\vect{q}_i$ and $\vect{k}_j$ are the query and key of pulses $i$ and $j$ and $d_k$ is the per-head dimension.
The attention weights are the row-wise softmax of $\mat{A}$, which then mixes the value vectors.

\subsection{Physical attention bias}\label{sec:method:attention:bias}

The first variant adds a pairwise bias to the attention logits, computed from the physical parameters of each pulse pair.
The bias uses two coordinates: the window-local \gls{toa} $t_n$ and the azimuth $\theta^{\mathrm{az}}_n$ of \cref{eq:method:aoa_cart}.
For \gls{toa} the pairwise feature is the absolute difference $B^{(t)}_{ij} = |t_i - t_j|$.
For azimuth, a plain absolute difference would treat bearings near $0$ and $2\pi$ as far apart although they describe nearly the same direction; the circular distance
\begin{equation}\label{eq:method:circ_az}
  B^{(\theta)}_{ij}
  =
  \frac{1}{\pi}\,
  \min\bigl(
    \lvert\theta^{\mathrm{az}}_i - \theta^{\mathrm{az}}_j\rvert,\,
    2\pi - \lvert\theta^{\mathrm{az}}_i - \theta^{\mathrm{az}}_j\rvert
  \bigr)
  \in [0,1]
\end{equation}
takes the shorter arc on the circle and normalises by $\pi$ so that both bias features lie in $[0,1]$.
Each feature is added to the logits with a learnable scalar coefficient,
\begin{equation}\label{eq:method:attn_bias}
  A_{ij}
  =
  \frac{\vect{q}_i^{\top}\vect{k}_j}{\sqrt{d_k}}
  + \lambda_t\, B^{(t)}_{ij}
  + \lambda_{\theta}\, B^{(\theta)}_{ij}.
\end{equation}
Each coefficient is learned jointly with the rest of the network and belongs to a single head of a single attention sub-layer, so every head in every encoder block---throughout the shared trunk and both branches---carries its own $(\lambda_t,\lambda_{\theta})$.
This adds only \(128\) scalar parameters in total, given the layer and head counts of \cref{sec:method:arch}; the pairwise delta matrices themselves scale quadratically in the window length, as the attention mechanism already does.
Coefficients may be negative, and each is initialised to a small negative value so that, in line with the intended inductive bias, a larger coordinate difference initially decreases attention between the corresponding pulses.
Because the coefficients are learned independently in each part of the network, the branches can weight the cues differently.
The deinterleaving branch is expected to rely more on azimuth, since pulses from one emitter usually arrive from a nearly constant bearing.
The shared trunk and the mode branch should instead suppress that cue, because an operating mode must be recognised independently of viewing geometry.
Whether this allocation emerges is examined in \cref{ch:experiments}.
The bias follows the same idea as additive pairwise attention biases in relative-position and graph Transformers \parencite{shaw2018relative,ying2021graphormer}, but uses continuous pulse parameters instead of discrete token or path distances.

\subsection{Rotary positional encoding}\label{sec:method:attention:rope}

The bias of \cref{eq:method:attn_bias} is added to the logits after the query--key product. The second variant uses the rotary encoding of \cref{sec:bg:transformer}, so the inner product depends on a pulse coordinate only through pairwise differences (\cref{eq:bg:rope}).

In the original construction the coordinate is the token index. Consecutive pulses in a recording are not equally spaced, so an ordinal index misrepresents \gls{toa} gaps (\cref{sec:method:data}). We attach physical coordinates instead, so that $p_j-p_i$ is a time gap or a difference of direction features.

Those coordinates lie in $[0,1]$ after the maps of \cref{sec:method:data}.
A token index over the same window would instead run through $\{0,\ldots,L-1\}$ in steps of one.
Feeding the unit interval to $\mat{R}(p)$ with the original frequencies would leave almost every plane unrotated: the first plane would turn by at most one radian from the start of the window to the end, and the slow planes by about $1/b$.
A scale $\gamma>0$ therefore stretches $p$ so that plane $m$ is rotated by $\gamma p\omega_m$. Equivalently, $\mat{R}$ is evaluated at $\gamma p$. The factor is left implicit in $\mat{R}$ below.

The base is kept at $b=10^4$ as in \textcite{su2024roformer}.
Changing $b$ would alter how quickly successive planes slow down, and therefore how large a gap the last plane can represent before wrapping.
Changing $\gamma$ multiplies every frequency, including the fastest, and maps the unit interval onto an effective index range of length $\gamma$.
Choosing $\gamma=L$ would give that interval the same numeric span as token indices on a window of this length.
A larger $\gamma$ gives a small gap in $p$ more phase and makes the fast planes wrap inside the window.
A smaller $\gamma$ keeps phases unique over a wider span of the window and flattens nearby distinctions.
Unlike the bias coefficients of \cref{eq:method:attn_bias}, $\gamma$ is not learned.
Each coordinate has its own scale, because a numerical gap of a given size is not the same physical distance in time as in direction.
The values $\gamma_t$, $\gamma_c$, and $\gamma_s$ are reported in \cref{ch:experiments}.

The encoder of \cref{sec:method:arch} uses this construction in every attention sub-layer. The shared trunk and the mode branch rotate by the window-local \gls{toa}. The deinterleaving branch splits each head across two continuous functions of azimuth.

\subsubsection*{Trunk and mode branch}

Every head in the shared trunk and in the mode branch rotates by the window-local \gls{toa}. With scale $\gamma_t$ in $\mat{R}$, the attention logit of pulses $i$ and $j$ is
\begin{equation}\label{eq:method:rope_toa}
  \bigl\langle \tilde{\vect{q}}_i,\, \tilde{\vect{k}}_j \bigr\rangle
  =
  \vect{q}_i^{\top}\,\mat{R}(t_j - t_i)\,\vect{k}_j.
\end{equation}
Arrival direction is excluded. An operating mode is characterized by the intrinsic temporal pattern of the emission and must be recognized regardless of viewing geometry. Rotating these layers by direction would make the mode embedding depend on that geometry.

\subsubsection*{Deinterleaving branch}

Every head in the deinterleaving branch rotates by direction instead.
Azimuth is a strong cue for emitter identity, and temporal structure is already present upstream through the \gls{toa}-rotated trunk.
Feeding the raw angle $\theta^{\mathrm{az}}_n$ into \gls{rope} would reintroduce the $0$--$2\pi$ wrap of \cref{sec:method:data:norm}, because the relative phase of \cref{eq:bg:rope} depends on the algebraic difference of the scalar coordinate.
The branch therefore replaces $\theta^{\mathrm{az}}_n$ by the two continuous features
\begin{equation}\label{eq:method:azimuth_trig}
  \tilde{c}_n = \frac{1 + \cos\theta^{\mathrm{az}}_n}{2},
  \qquad
  \tilde{s}_n = \frac{1 + \sin\theta^{\mathrm{az}}_n}{2},
\end{equation}
both in $[0,1]$.
The $d_k/2$ planes of each head are split evenly into two slices of $d_k/4$ planes, following multi-axis \gls{rope} \parencite{heo2024ropevit}, so that the query (and likewise the key) decomposes as
\begin{equation}\label{eq:method:rope_split}
  \vect{q}_n
  =
  \begin{bmatrix}
    \vect{q}_n^{(c)} \\
    \vect{q}_n^{(s)}
  \end{bmatrix},
  \qquad
  \vect{q}_n^{(c)},\, \vect{q}_n^{(s)} \in \R^{d_k/2}.
\end{equation}
Each half is rotated by its own single-coordinate matrix of the form \cref{eq:bg:rope_block},
\begin{equation}\label{eq:method:rope_az}
  \mat{R}^{\mathrm{em}}_n
  =
  \diag\!\bigl(
    \mat{R}^{(c)}(\tilde{c}_n),\;
    \mat{R}^{(s)}(\tilde{s}_n)
  \bigr),
\end{equation}
with $\mat{R}^{(c)},\mat{R}^{(s)}\in\R^{d_k/2\times d_k/2}$ using scales $\gamma_c$ and $\gamma_s$ respectively.
The two halves of the query are then
\begin{equation}\label{eq:method:rope_az_q}
  \tilde{\vect{q}}_n^{(c)}
  =
  \mat{R}^{(c)}(\tilde{c}_n)\,\vect{q}_n^{(c)},
  \qquad
  \tilde{\vect{q}}_n^{(s)}
  =
  \mat{R}^{(s)}(\tilde{s}_n)\,\vect{q}_n^{(s)},
\end{equation}
and likewise for the key.
The cosine rotation acts only on $\vect{q}_n^{(c)}$, the sine rotation only on $\vect{q}_n^{(s)}$.
Because the slices occupy disjoint coordinates, the head inner product is the sum of two half-dimension inner products,
\begin{align}
  \bigl\langle \tilde{\vect{q}}_i,\, \tilde{\vect{k}}_j \bigr\rangle
  &=
  \bigl\langle \tilde{\vect{q}}_i^{(c)},\, \tilde{\vect{k}}_j^{(c)} \bigr\rangle
  +
  \bigl\langle \tilde{\vect{q}}_i^{(s)},\, \tilde{\vect{k}}_j^{(s)} \bigr\rangle
  \nonumber
  \\
  &=
  \vect{q}_i^{(c)\top}\,
  \mat{R}^{(c)}\bigl(\tilde{c}_j - \tilde{c}_i\bigr)\,
  \vect{k}_j^{(c)}
  +
  \vect{q}_i^{(s)\top}\,
  \mat{R}^{(s)}\bigl(\tilde{s}_j - \tilde{s}_i\bigr)\,
  \vect{k}_j^{(s)}.
  \label{eq:method:rope_az_logit}
\end{align}
Two bearings just above $0$ and just below $2\pi$ are almost the same direction, but their raw angles differ by nearly a full turn.
Their $(\tilde{c},\tilde{s})$ values are almost the same, so the relative phase in \cref{eq:method:rope_az_logit} stays small.
An algebraic gap in $\theta^{\mathrm{az}}$ itself would not.

A control that rotates every layer of the trunk and of both branches by window-local \gls{toa}, with no azimuth encoding, is evaluated in \cref{ch:experiments}.
That uniform layout tests whether the branch-specific allocation above is necessary, or whether a single temporal coordinate already suffices.
