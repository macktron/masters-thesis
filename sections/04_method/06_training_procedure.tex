\section{Training Procedure}\label{sec:method:training}

Parameters $\bm{\theta}$ are estimated by minimising $\Loss$
(\cref{eq:method:loss_total}) with Adam \parencite{kingma2014adam}.
Learning rate, weight decay, epoch count, dropout, and related
settings are listed in \cref{tab:exp:hparams_main}.

\subsection*{Scenario-aware batch sampling}\label{sec:method:training:sampler}

Mini-batches are not formed by uniform shuffling of the pooled windows.
Overlapping windows from \cref{sec:method:data:window} must co-occur
in a batch to act as shifted views under the contrastive objective, and
emitter identifiers are recording-local
(\cref{sec:method:formulation}), so cross-window emitter positives
exist only within a scenario.
Each mini-batch is therefore assembled from a small number of
scenarios, each contributing several (possibly overlapping) windows.
Within a scenario group the emitter branch obtains cross-window
positives; across groups the mode branch obtains batch-wide
negatives and cross-scenario mode positives as required by
\cref{sec:method:loss}.
The number of groups and windows per group, together with any
$\lambda_{\mathrm{md}}$ warm-up or early-stopping policy, are
recorded in \cref{tab:exp:hparams_main}.
