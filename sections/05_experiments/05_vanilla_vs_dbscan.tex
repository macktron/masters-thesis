\section{Joint Encoder versus Feature DBSCAN}\label{sec:exp:results}\label{sec:exp:results:vanilla}

Vanilla is the encoder of \cref{sec:method:arch} with standard \gls{mha}, trained with the joint objective of \cref{eq:method:loss_total}.
No positional encodings are used and \Gls{toa} enters only as an input feature.
Feature \gls{dbscan} is the no-encoder control of \cref{sec:method:baselines}.
\Cref{tab:exp:vanilla} reports both branches, so the two tasks can be compared before any attention variant is introduced.

Feature \gls{dbscan} sits well below Vanilla on both branches.
Emitter $\ARI$ is $0.578$, and $71\%$ of windows fall below $0.90$.
Completeness is $0.523$ and the mean count error exceeds seven emitters, so the method oversplits.
Homogeneity remains $0.976$: the extra clusters are internally pure.
Mode $\ARI$ is $0.811$, still below Vanilla, with a mean count error of five modes.

Emitter $\ARI$ is $0.948$, and $88\%$ of windows score at or above $0.99$, but about one window in ten falls below $0.90$.
That tail is what widens the standard deviation.
Mode recovery is stronger: mean $\ARI$ $0.985$, with only $2.5\%$ of windows below $0.90$.
Vanilla therefore still leaves a tail of failed deinterleaving windows, while the mode branch is already recovered on almost every window.
Feature \gls{dbscan} already ranks the tasks in the same order, with higher mode $\ARI$ and $\AMI$ and a lower mode count error than on emitters.
The mode partition is already more separable in the raw PDW features and the encoder inherits that gap rather than creating it.
The input geometry of \cref{fig:exp:feat_scan,fig:exp:feat_imbalance,fig:exp:feat_maxemitters,fig:exp:feat_maxmode} makes that ranking visible before any encoder is trained.
A scanning track is not a compact cluster, a $3$/$1997$ split is easy to miss, and crowded windows share a handful of frequency and pulse-width bands among many labels.
A density clusterer on those scaled coordinates oversplits; Vanilla is trained to recover both partitions from the same four channels.
The per-window emitter tail is the Vanilla curve of \cref{fig:exp:hist_em}; the corresponding count errors are the Vanilla panel of \cref{fig:exp:kcorr_em}.
