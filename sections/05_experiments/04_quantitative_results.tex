\subsection{Evaluation Protocol}\label{sec:exp:results:protocol}

All scores are computed on the held-out test split of \cref{sec:exp:datasets}.
Every model is scored with window length $L = 2000$ and with no overlap between scored windows.
The neural test dumps are generated at stride $\delta = L$ and comprise $1168$ windows over the $244$ test scenarios.
Feature \gls{dbscan} of \cref{sec:method:baselines} clusters the scaled \gls{pdw} vector of each pulse directly.
It is not trained, and its test dump already uses overlap $0$ at the same $L$, with $1412$ windows.
For each window, \gls{dbscan} on each branch yields an estimated partition that is scored against the simulator labels with $\ARI$, $\AMI$, homogeneity, and completeness (\cref{sec:method:metrics}).

Each neural table entry is the mean $\pm$ one standard deviation of that per-window score over the $1168$ windows.
The \gls{dbscan} radius $\varepsilon$ is selected independently for each model and each branch on the validation grid of \cref{sec:method:arch}, with $\mathrm{minPts} = 5$ throughout; selected radii are listed in \cref{tab:exp:hparams_attn}.

Homogeneity and completeness are reported separately rather than only through their harmonic mean, the \gls{vmeasure}, so that oversplitting can be distinguished from undermerging.
Mean absolute cluster-count error $\lvert\hat{K}-K\rvert$ (emitters) and $\lvert\hat{M}-M\rvert$ (modes) summarises how well the inferred number of clusters matches the number of distinct reference labels in the same window.

\subsection{Joint Vanilla Encoder}\label{sec:exp:results:vanilla}

Vanilla is the encoder of \cref{sec:method:arch} with standard \gls{mha}, trained with the joint objective of \cref{eq:method:loss_total}.
\Gls{toa} enters only as an input feature.
Feature \gls{dbscan} is the no-encoder control of \cref{sec:method:baselines}.
\Cref{tab:exp:vanilla} reports both branches on the same windows, so the two tasks can be compared before any attention variant is introduced.

Feature \gls{dbscan} sits well below Vanilla on both branches.
Emitter $\ARI$ is $0.578$, and $71\%$ of windows fall below $0.90$.
Completeness is $0.523$ and the mean count error exceeds seven emitters, so the method oversplits.
Homogeneity remains $0.976$: the extra clusters are internally pure.
Mode $\ARI$ is $0.811$, still below Vanilla, with a mean count error of five modes.

Vanilla already recovers both partitions on this corpus, which is the existence test of RQ1.
Emitter $\ARI$ is $0.948$, and $88\%$ of windows score at or above $0.99$, but about one window in ten falls below $0.90$.
That tail is what widens the standard deviation.
Mode recovery is stronger: mean $\ARI$ $0.985$, with only $2.5\%$ of windows below $0.90$.
The two tasks are therefore not equally hard for this encoder.
Deinterleaving is the branch that still fails on a minority of windows; mode clustering is already tight on almost every window.
The per-window emitter tail is the Vanilla curve of \cref{fig:exp:hist_em}; the corresponding count errors are the Vanilla panel of \cref{fig:exp:kcorr_em}.
