\section{Objectives and Scope}\label{sec:intro:scope}

\subsection{Objectives}\label{sec:intro:objectives}

We implement a transformer encoder that maps windows of \glspl{pdw} to emitter and mode embeddings, cluster each embedding independently, and measure agreement with simulator labels using \gls{ami}, \gls{ari}, and \gls{vmeasure} (\cref{sec:method:formulation,sec:method:arch,ch:experiments}).
We train with two supervised contrastive terms---recording-local emitter positives and batch-wide mode positives---and compare that joint loss with a deinterleaving-only baseline of similar capacity (\cref{sec:method:loss,ch:experiments}).
We compare standard self-attention with a physical pairwise bias, rotary positional encoding, and both together (\cref{sec:method:attention,ch:experiments}).

\subsection{Delimitations}\label{sec:intro:delimitations}

The model sees \glspl{pdw}, not raw radio-frequency samples.
Pulse detection, receiver processing, and multi-platform fusion are out of scope.

All data come from a proprietary scenario simulator (\cref{sec:method:data}).
No operational \gls{elint} recordings are used, so the results do not speak to real-world distribution shift.
Dropped pulses and spurious detections, when present, are simulator artifacts.

The study is offline analysis of recorded streams, not real-time inference on embedded hardware.
The encoder does not name emitters against a classified library.
Self-attention scales with the square of window length, so each recording is split into windows of fixed length (\cref{sec:method:data:window}).
Scores therefore describe clustering on those windows, not tracking over an unbounded stream.

Every evaluation scenario uses the same mode catalogue as training (\cref{sec:exp:datasets}).
Held-out modulation types are not tested.
